# Reine & Tresses : site Next.js (multi-pages, police Poppins)

    npm install
    npm run dev      # http://localhost:3000

Pages : / · /a-propos · /catalogue · /formations (+ 9 sous-pages) · /conseils · /fidelite · /contact

1. Remplir `lib/config.js` (WhatsApp, téléphone, adresse, horaires, intitulés des formations).
2. Ajouter les photos dans `public/images/` (voir LISEZ-MOI.txt).
3. Déployer : GitHub puis vercel.com.

Couleur d'accent : `--accent` en haut de `app/globals.css` (noir, violet : `#5b2a9e`).
Police : `app/layout.jsx` (Poppins) et variables `--display` / `--body` dans le CSS.
